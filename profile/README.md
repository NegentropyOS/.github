### What is Negentropy AI?

**Negentropy AI** builds deterministic, sovereign infrastructure for autonomous agents. While large language models provide statistical intelligence, enterprise systems demand predictable memory, verified context, and auditable state. We isolate probabilistic inference behind strict schemas and persistent, ACID-compliant storage.
